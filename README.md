# Dashboard de ventas e inventario de un supermercado

Dashboard web hecho con **HTML, CSS y JavaScript** (gráficos con Chart.js). Muestra cómo se mueven las ventas de un supermercado y qué productos necesitan reposición.

## Objetivo

- ¿Qué categorías venden más?
- ¿Cómo cambian las ventas mes a mes?
- ¿Qué productos están por debajo del stock mínimo?

## Datos

Datos de ejemplo creados para este proyecto (no son datos reales de ninguna empresa):
- `ventas.csv`: ventas por fecha, producto, categoría, cantidad y método de pago.
- `inventario.csv`: stock actual y stock mínimo por producto.

## Qué incluye

- Total de ventas, unidades vendidas, venta promedio y productos por reponer
- Ventas por mes, por categoría y por método de pago
- Tabla de inventario con estado "Reponer" o "Suficiente"

## Cómo verlo

Abre `index.html` en el navegador, o visita la página publicada con GitHub Pages.
